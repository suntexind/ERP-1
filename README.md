# Factory Performance Input

This project is a simple production entry and tracking page for factory operations.

## Features
- production input form
- shift, line, operator, product tracking
- live performance summary cards
- data log table
- CSV export for reporting
- local browser storage so saved entries remain on refresh

## Run it locally
Open `index.html` in a browser.

If you want a full backend version later, this can be upgraded to Node.js, PHP, or a database-backed ERP module.
